**Goal:** Close the last open item in Human Approval RBAC — reach role administration over HTTP.
**Input:** An admin principal's grant/revoke request over real Bearer-authenticated HTTP.
**Output:** A real, persisted, audited grant/revoke via `POST`/`DELETE /api/v1/security/role-grants`.

T07's own ticket + `routes/approvals.py` (T06) were sufficient — no fork.
Reused T06's exact shape: bare `authenticate` (no flat permission check),
authorization deferred entirely to `RoleAdministrationService`, which
already gets `admin`-gating right. Revoke is a body-carrying `DELETE`
(role strings like `approver:release` avoid path-param colon-encoding).
Proven via real Postgres + `TestClient`: an admin genuinely grants then
revokes through the route (read back directly from `security.role_grants`,
one real audit row each); a non-admin request to either endpoint is
refused `403`, no real grant made. Wired into `bootstrap.py`'s router set.
