**Goal:** Persist approval requests and decisions (FR-111).
**Input:** An approval decision.
**Output:** A durable approvals row.

Built alongside T04 (the writer alone has no real caller without the pause
mechanism). `SqlApprovalRepository` (`workflow_engine/human_approval.py` —
the `workflow.approvals` table's own schema, real writer lives beside the
other workflow-state repositories, not security_manager) creates a real
`pending` row, and `decide()` atomically records a real, attributable
decision (`principal_id` required, never blank) and resumes the paused
instance in one transaction, guarded against a double-decide
(`ApprovalNotPendingError`). No HTTP route, no RBAC — product-owner-approved
scope, see `human_approval.py`'s own module docstring.
