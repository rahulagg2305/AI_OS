**Input:** Tool declarations.
**Output:** Registry-resolvable Tools.

Two real Kernel bugs found and fixed, blocking any pack tool ever:
(1) trust-tier check used `is not` (identity) against Kernel's own
enum, which no pack (forbidden from importing `ai_os_kernel`) could
ever satisfy — fixed to `!=`. (2) `PackContext` had no `sandbox` field,
so no `tier1_sandboxed` tool could satisfy `SandboxBackedTool` —
`SqlToolRegistry` now injects it directly (design fork resolved with
product owner). Built `fs.read`/`build.run`, proven end to end via a
real registry + real sandbox; not yet adopted by any agent.
