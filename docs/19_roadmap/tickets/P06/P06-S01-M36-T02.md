**Goal:** Return problem+json errors consistently.
**Input:** Any error.
**Output:** An RFC 9457 body.

Every route raises plain HTTPException today (confirmed by inspection);
migrating each onto AiOsError for its own real error_code is separate,
larger work. Built instead: 3 generic exception handlers (HTTPException,
RequestValidationError w/ real violations array, catch-all 500 that
never leaks the real message) applied uniformly, no per-route change.
error_code/type/title honestly coarse (status-derived) -- no catalogue
exists yet. detail key kept identical to the old body: zero regression.
