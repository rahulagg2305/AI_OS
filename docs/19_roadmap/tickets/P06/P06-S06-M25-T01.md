**Goal:** Wake word, intent recognition, spoken response (ADR-0019).
**Input:** Audio input.
**Output:** Recognised intent plus spoken output.

Real abstraction, no real provider — a structural gap disclosed via
`AskUserQuestion` before writing provider code: every ADR-0019 adapter
(faster-whisper, Piper, openWakeWord, cloud STT/TTS) needs
infrastructure this repo lacks (no ML runtime, no speech credential).
Built the real `SpeechGateway`/alias-routing abstraction (mirrors
`LLMGateway`) plus one deterministic `echo_adapter.py`, mirroring
`EchoLLMGateway`. Intent recognition is out of scope by ADR-0019
itself. Built inside the Kernel, not `platform_services/` (no real
workspace member exists — Notification Service precedent). Not wired
into `bootstrap.py` — no real caller (Voice pack still 0%).
