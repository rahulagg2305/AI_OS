**Goal:** Fuse keyword and vector results (ADR-0013).
**Input:** Two ranked lists.
**Output:** One fused ranking.

Not a fork: ADR-0013's own "no tuning parameter per corpus" line
confirms the standard fixed-k RRF formula (k=60, the published
constant). `fuse_rankings()` is pure, no I/O -- consumes the real
keyword/vector lists, no parallel mechanism. 5 real tests: fused order
provably differs from both inputs, hand-computed scores match, one-
list-only presence still scores, ties break on chunk_id. Zero
regression.
