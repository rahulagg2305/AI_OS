**Goal:** Resolve a pack-declared Tool through the registry, not an internal shim.
**Input:** A declared toolId.
**Output:** A resolved, trust-tiered Tool.

`ToolInvokerAdapter`, given an optional `ToolRegistry`, now resolves any
non-shim `tool_id` through the real `SqlToolRegistry` path (catalog lookup,
pack-activation gate, T08 permission-grant check, tier1-sandboxed guard —
all reused, not reimplemented) and invokes the resolved `Tool` for real.
`available_tools()` unchanged: `ToolRegistry` has no "list all" capability
to draw from, a disclosed, distinct gap. Backward compatible: `registry`
defaults to `None`, unchanged behavior for every existing caller.
