**Goal:** Make the artifact store reachable from a running system.
**Input:** A workflow artifact.
**Output:** An artifact stored through a real, injected Protocol.
Verified 2026-08-13: `LocalFilesystemArtifactStore` is real and tested
but has **zero production importers** (risk register R-018 item 7,
machine-checked by `tests/contract/test_production_reachability.py`).
`storage_service.md` §5 names a `StorageService` Protocol; only the one
concrete class exists. Workflow artifacts remain plain files in
per-agent temp directories.
Adding the Protocol is ADR-0004's substitution seam and is
uncontroversial. **Expect a design fork on the caller:** which producer
writes artifacts through it, and whether existing pack agents change
behaviour. Wiring it into a composition that then writes nothing would
be the same hollow wiring R-018 exists to prevent — stop and ask.
