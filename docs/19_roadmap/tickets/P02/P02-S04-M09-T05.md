**Input:** A retrieved item.
**Output:** Source plus version.

Not a schema-authority fork (unlike the last step): version fields
already exist, documented, in data_model.md §7 (`chunk_strategy_version`,
`embedding_model_id`/`version`/`index_generation`) -- surfaced onto
`KnowledgeQueryResult` via QueryEngine's existing join, no new table.
Deliberately not built: a Version Manager deciding what a new
generation means (already-disclosed, separate gap). 3 real Postgres
tests: version always present, embedding provenance genuinely absent
(not fabricated) for keyword-only hits, highest generation wins
deterministically on a real tie. Zero regression.
