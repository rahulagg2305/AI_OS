**Goal:** `caching_strategy.md` §1's own `Cache` Protocol.
**Input:** A cache operation.
**Output:** A Protocol plus a real in-memory implementation.
Verified 2026-08-13 against that document's Not-built paragraph: this
module has "a concrete `ResponseCache` only, no Protocol, no in-memory
test adapter". Every cache call therefore requires a real Redis
container, which is why nothing outside this package's own tests
exercises caching at all.
The in-memory adapter is the point, not a bonus: it is ADR-0004's
substitution seam, and it is what lets `T04` wire caching into the LLM
Gateway without forcing Redis into every test that touches a model
call.
No design fork expected — one Protocol, one existing implementation to
conform, one new adapter. Deliberately first in this module's chain.
