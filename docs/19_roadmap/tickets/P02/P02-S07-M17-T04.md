**Goal:** Give `platform.event_outbox` its first real writer and start the relay.
**Input:** A committed workflow completion.
**Output:** A delivered notification.

`write_outbox_event` takes the caller's `AsyncConnection`, not an
engine, so the row joins the transaction that produced the state change
— ADR-0012's actual guarantee. First producer: `advance_workflow`'s
terminal branch, where `"workflow.completed"` was already emitted to
`workflow_events`. `run_outbox_relay_loop` now runs in `bootstrap.py`,
so completion reaches the already-subscribed `NotificationService`.
Mechanism was not a choice: `event_bus.md` §5's table assigns workflow
lifecycle to the outbox. 4 real Postgres tests incl. rollback leaving no
row. Closes R-018 for the relay + table. `workflow.failed` (no write
site exists) and `approval.*` stay unwired; relay retry stays unbounded.
