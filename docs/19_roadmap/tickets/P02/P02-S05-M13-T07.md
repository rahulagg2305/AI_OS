**Goal:** Upgrade an activated pack to a new version safely.
**Input:** A newer pack version.
**Output:** A migrated, activated pack.

`SqlPackLifecycleRepository.upgrade()` migrates an activated pack's
`packs`/`agents`/`tools`/`prompts` rows to a new manifest version in one
transaction, refusing a same-or-older version first. capability_manager.md
§9's own 3 open questions: (c) and (a) answered by the existing schema
(single row per pack_id; no `upgrading` state to model); (b) — in-flight
workflow instances of the old version — remains genuinely open, disclosed.
Built without the ADR §9 said this "warrants," a disclosed product-owner
decision to proceed now, not an oversight.
