**Goal:** Refuse to resolve an agent whose permissions exceed its pack grant.
**Input:** An agent row.
**Output:** Refusal on over-grant.

`catalog.agents.required_permissions`/`catalog.tools.required_permissions`
(manifest-sourced, real since T01's installer) are now checked against
`catalog.packs.manifest`'s own top-level `permissions` at resolution, in
`SqlAgentRegistry.resolve_agent`/`SqlToolRegistry.resolve_tool`, before the
entrypoint is ever loaded. Reuses T03's `narrow_permissions` primitive
(`intersect_declared_permissions`) via a new
`capability_manager.permission_grant.over_granted_permissions` rather than
a bespoke subset check. Covers agent and tool paths; the workflow term of
ADR-0023's full chain still has no data source (unchanged by this ticket).
