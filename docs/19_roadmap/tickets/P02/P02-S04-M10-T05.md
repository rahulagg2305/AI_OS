**Goal:** Make `knowledge.memory_items.provenance` mean something.
**Input:** A memory write.
**Output:** Provenance the platform computed, not the caller asserted.
Verified 2026-08-13 against `memory_manager.md`'s own Not-built
paragraph: the `provenance` column is real and write-through, but
"nothing computes a value for it beyond what a caller already
supplies". A caller can therefore write any provenance it likes,
including none — the field is decorative today.
Real inputs already exist to compute it honestly: the writing workflow
(`source_workflow_id`, a real FK), the step, and the agent. The Context
Manager already models trust (`ContextItem.trust`) and the Project
Intelligence pack already mirrors it (`provenance.py`), so there is
precedent for the shape.
Smaller and better-defined than `T04`; do it after, since the mediated
write path is where computation belongs.
