**Goal:** Store workflow artifacts by content hash instead of temp directories.
**Input:** An artifact.
**Output:** An addressable, retrievable object.

Real `LocalFilesystemArtifactStore`: SHA-256 content addressing,
returns the real, pre-existing SDK `ArtifactRef` (`sha256:<hex>`), not
a new shape. No S3 backend/Protocol (no second real implementation
exists, ADR-0004). 11 real tests, real filesystem: dedup to one file,
distinct content diverges, round trip, malformed-id rejection. Not
wired into any caller yet. Zero regression: 995 unit tests (984 + 11).
