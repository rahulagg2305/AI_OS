**Goal:** Mark where a provider prompt cache should split.
**Input:** A template.
**Output:** Boundary annotations.

Real fork, stopped: ADR-0025 says what stable/volatile means, not how
to detect it from text -- inventing a heuristic would be a guess (same
class of gap `P02-S04-M10-T03` avoided). Chosen: a real
`{{cache_boundary}}` marker, consistent with `{{variable}}` syntax.
Index is computed on real *rendered* text (each side rendered
separately via unchanged `render_template`), not the raw template --
substitution before the boundary shifts real length. Standalone
utility, no `PromptRenderResponse`/`PromptEngine` change. 8 real
tests: correct split, missing/duplicate marker rejected, real
length-shift proven distinct from raw offset, empty-side edges. Zero
regression.
