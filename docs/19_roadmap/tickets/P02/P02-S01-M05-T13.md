**Goal:** Start a workflow on a schedule or after a delay.
**Input:** A schedule declaration.
**Output:** A started instance at the right time.

No fork stopped on (mirrors 2 approved precedents: Lease Reaper's
tick+loop shape, Worker Loop's background-task wiring). New nullable
`workflow_instances.scheduled_at` (migration 0032); `create()` gains
the same optional kwarg every prior term used. New `WorkflowScheduler`/
`run_scheduler_loop`, a 5th `_lifespan` task, drained by
`GracefulShutdownCoordinator`. Proven real, Postgres:
list_startable_instances finds only due/created/scheduled instances;
tick_once starts them, treats a raced already-started instance as a
skip not a failure; a full _lifespan test starts+completes a real
instance with zero manual calls, leaves a not-yet-due one alone. Zero
regression: 969 unit + 317 integration + roadmap tests all pass.
