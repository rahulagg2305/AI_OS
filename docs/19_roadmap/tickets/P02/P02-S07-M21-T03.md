**Goal:** `storage_service.md` §5's second documented backend adapter.
**Input:** Artifact bytes.
**Output:** An object in S3-compatible storage.
Verified 2026-08-13: the document names `local` and `s3` adapters; only
`local` exists. Its own Not-built paragraph states there is **no S3
client dependency, configuration, or endpoint anywhere in this
codebase** to build or test one against.
Depends on `T02` for a real reason, not sequencing: without the
Protocol there is nothing for a second adapter to implement, and
ADR-0004 says a second implementation is what justifies the Protocol.
**Expect a design fork before any code:** this needs a new third-party
dependency (`boto3` or `minio`) — the same class of decision the
product owner declined for PDF/DOCX on 2026-08-13, on the ground that
the package had no production caller. Ask; do not assume the answer
differs here.
