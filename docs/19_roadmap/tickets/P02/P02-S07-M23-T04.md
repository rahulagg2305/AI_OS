**Goal:** Make the Response Cache actually cache something in production.
**Input:** A real `LLMRequest` on the real gateway path.
**Output:** A genuine cache hit that avoids a real, billable model call.
Verified 2026-08-13: `ResponseCache` is real, tested against a real
Redis container, and has **zero production importers** — R-018 item 7,
machine-checked. `caching_strategy.md` says outright it "is not wired
into `llm_gateway.gateway`'s real call path yet".
This is the single highest-value wiring in the module: it turns a
tested-but-idle component into real cost reduction on every repeated
call.
**Expect a design fork.** Caching a model call changes behaviour and
billing, so at minimum: default on or off; TTL; and what happens when
Redis is unreachable (fail open and call the provider, or fail closed).
ADR-0025 §3's experiment-exclusion rule is already enforced
structurally, so that part is settled. Stop and ask on the rest.
