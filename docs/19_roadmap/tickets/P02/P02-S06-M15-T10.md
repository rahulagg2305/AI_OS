**Goal:** §5's Observability Hook, the one component of this package with no code.
**Input:** A real gate resolution.
**Output:** Real structured logs, metrics and spans for gate execution.
Verified by inspection: the package was `__init__.py`, `errors.py` and
`registry.py`, and searching it for `logger`/`metric`/`span` returned
nothing — §8's observability requirements had no producer at all.
Now real: a `quality_gate.resolved`/`.blocked` structured event, an
`aios.quality_gate.resolutions` counter (created once and cached, the
`get_http_requests_counter` contract), and a real span around execution.
**Blocked and warning failures are deliberately distinct outcomes** —
ADR-0006 treats them differently, so collapsing both into "failed" would
make the metric unable to answer the question operators actually ask.
**Telemetry only, never a second store**, and guarded throughout: a
metric outage must not fail a gate that passed. Proven by 5 new tests
over structlog's own real capture, not mocks. 14 pass.
