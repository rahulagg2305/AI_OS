**Goal:** Notify a real person when a workflow waits on their approval.
**Input:** A committed approval request or decision.
**Output:** A delivered notification.

A run could pause durably on a *human* and tell nobody: zero `approval.*`
producers existed, so `NotificationService`'s approval branch had never
fired. `create_pending` and `decide` now each `write_outbox_event` inside
their own existing transaction — `approval.requested` and
`approval.decided`, the latter carrying `decided_by` (R-001 makes
attribution a hard rule). Mechanism prescribed by `event_bus.md` §5, not
chosen. 3 real Postgres tests, incl. a refused double-decide announcing
nothing — a decision that does not commit is never published.
`P06-S05-M22-T01` stays `partial`: only `failure` remains, and it is
blocked by R-016 (nothing ever persists an instance as `failed`).
