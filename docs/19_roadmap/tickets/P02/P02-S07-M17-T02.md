**Goal:** Publish and subscribe in-process.
**Input:** An event.
**Output:** Delivered to subscribers.

Real `InProcessEventBus`: bounded per-subscriber `asyncio.Queue`,
non-blocking `publish` (drop + log on backpressure), typed/versioned
Pydantic `Event` (event_bus.md §5/§9), `aclose()` for real shutdown.
9 real tests: fan-out, type filtering, wildcard, slow subscriber
isolation, unsubscribe, backpressure drop, failing-handler isolation.
Scope: the in-process box only, per event_bus.md §4 -- not the Outbox,
Relay, Topic Manager, or Schema Registry. Zero regression: 978 unit
tests (969 + 9 new).
