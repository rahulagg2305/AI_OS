**Goal:** Make §4's "ingest knowledge from approved sources" automatic, not merely callable.
**Input:** Real project content on disk.
**Output:** Indexed, queryable knowledge produced by a running process.
Verified 2026-08-13: `index_document_file` has **no production caller**
anywhere in `kernel/src` — confirmed by direct search. `knowledge_manager.md`
names this exactly: "no real production composition calls
`index_document_file` itself (no `bootstrap.py`/API route wiring)", so
ingestion is "reachable, not yet automatic".
The whole chain beneath it is real and proven: format detection, three
parser adapters, chunking, and the knowledge writer.
**Expect a design fork:** what triggers ingestion is genuinely
undecided — an HTTP route, a startup scan of a configured directory, or
a workflow step — and each implies a different security posture for
content the platform treats as untrusted. Stop and ask.
