**Goal:** Remove a real R-015 recurrence found 2026-08-13.
**Input:** `tests/unit/kernel/notification/test_service.py`.
**Output:** A deadline that cannot expire while the code is behaving.
**A test defect, not a product defect, and the numbers proved it.**
`WebhookChannel`'s per-delivery timeout is **5.0s**; this file gave
**two** sequential deliveries **2.0s total**, so the assertion could
fail while every component behaved exactly as designed.
**The fix is the link, not a bigger number:** the deadline is now
derived from the real production constant
(`5.0 x 2 + 1.0 grace = 11.0s`), so changing that timeout can never
again silently outrun this file's patience.
Proven by A/B under identical, real CPU load (16 spinners): the old
flat `2.0` **failed**; the derived `11.0` passed **4/4**, including
runs of 37.6s and 35.5s wall time that the old deadline would have
blown many times over. 5/5 idle both before and after.
