**Goal:** Replace the pre-shared JWT with real OIDC (ADR-0023).
**Input:** An OIDC provider.
**Output:** Federated authentication.

Real JWKS-based RS256 verification (issuer+audience checked), proven
against a real, self-hosted JWKS HTTP server + real RSA-signed tokens
(no mock). Design decision, not a fork: kept the pre-shared HS256
verifier as the zero-config default rather than literally "replacing"
it — no environment configures a real OIDC provider yet, so removing
it would break every current environment. bootstrap picks OIDC only
when all 3 fields (issuer/audience/jwks_uri) are configured together.
